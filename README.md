# Fake News Detection using TF-IDF and Passive Aggressive Classifier

KZ-ML-02 — see the capstone spec for full background, viva Q&A, and diagram list.

## Setup

```
pip install -r requirements.txt
```

## Dataset

`data/Fake.csv` and `data/True.csv` contain the real 44,898-article Kaggle dataset
(23,481 fake + 21,417 real) — see [data/README.md](data/README.md) for provenance and
how to re-fetch it if needed.

## Train the models

```
python train_model.py
```

This loads the dataset, removes the Reuters dateline leakage, cleans the text,
builds TF-IDF features, trains Passive Aggressive / Naive Bayes / Logistic Regression,
prints a comparison table, and saves:

- `model/model.pkl` — the best model by F1-score
- `model/tfidf.pkl` — the fitted vectoriser
- `reports/metrics.json` — accuracy/precision/recall/F1 for all 3 models
- `reports/*.png` — confusion matrices, model comparison bar chart, word clouds (for the report)

Alternatively, open `notebook/fake_news_training.ipynb` to walk through the same
pipeline interactively with inline charts.

## Run the web app

```
python app.py
```

Visit http://127.0.0.1:5000 to paste an article and get a REAL/FAKE prediction with a
confidence percentage. Past checks are stored in `checks.db` (SQLite) and viewable at
`/history`.

The result page also shows related web search results for the headline (via the `ddgs`
DuckDuckGo search library, no API key needed) — like a mini search engine, so users can
cross-check the prediction against real sources instead of trusting the model blindly.
Requires internet access at request time; if the search fails or is unavailable, the
section just shows "no related results" and the real/fake prediction still works.

```
  train_model.py   CLI entry point for training
  templates/       index.html, result.html, history.html
  checks.db        SQLite history (created at runtime)
  requirements.txt
```
